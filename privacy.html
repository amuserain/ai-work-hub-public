AI Work Hub 홈페이지

개인정보처리방침

시행일: 2026년 11월 24일

AI Work Hub는 개인 업무 및 프로젝트 관리를 위한 개발 중인 AI 보조 서비스입니다. 다음은 서비스의 Google 사용자 데이터 및 개인 정보 처리에 관한 설명입니다.

1. 처리하는 정보

  • 사용자가 입력한 대화, 작업 요청 및 생성된 결과물
  • Google OAuth를 통해 승인받은 접근 토큰, 접근 권한과 연결 계정 정보
  • 사용자가 허용한 Google Drive 파일, 폴더 정보 및 백업 파일
  • 서비스 기능의 정상 작동에 필요한 최소한의 이용·오류 기록

2. 이용 목적과 Google Drive 연동

데이터는 사용자가 요청한 AI 대화, 업무 기록 정리, 파일 조회, 백업 저장과 백업 무결성 점검을 위해 사용합니다. Google Drive 데이터는 사용자가 허용한 기능 범위에서만 이용하며 광고 타겟팅이나 데이터 판매에 사용하지 않습니다.

3. 저장 장소와 보관 기간

기록은 기능에 따라 Google Cloud Firestore 또는 사용자가 연결한 Google Drive에 저장될 수 있습니다. 인증 토큰은 별도의 비밀 관리 서비스로 보호합니다. 데이터는 서비스 이용과 백업 목적에 필요한 동안 유지하며, 삭제 요청이나 서비스 종료 시 관련 백업과 보관 정책을 확인해 처리합니다. 백업본은 원본과 삭제 시점이 다를 수 있습니다.

4. 제3자 처리

Google Drive 및 Google Cloud의 해당 기능을 이용하기 위해 관련 서비스로 데이터가 처리됩니다. AI 답변 생성 기능을 사용할 경우 해당 요청에 필요한 대화 내용 또는 사용자가 지정한 일부 자료가 AI 모델 API 제공업체로 전송되어 처리될 수 있습니다. 그 밖의 용도로 Google 사용자 데이터를 판매하거나 광고주에게 제공하지 않습니다.

5. Google API 이용 정책

Google API를 통해 수집한 정보는 사용자가 승인한 서비스 기능을 제공하는 데 필요한 범위에서 사용하며, Google API Services User Data Policy의 적용 가능한 요구사항을 따르도록 운영합니다.

6. 접근 권한 철회 및 삭제 요청

사용자는 Google 계정의 제3자 앱 연결 설정에서 AI Work Hub의 접근 권한을 철회할 수 있습니다. 보관된 기록의 열람 및 삭제 요청은 아래 이메일로 연락해 주세요. 계정 접근 권한을 철회하더라도 이미 생성된 백업 파일이 자동으로 모두 삭제되지는 않을 수 있습니다.

7. 보안 및 변경

접근 권한 제한, 토큰의 별도 보관 및 업무 공간 분리를 통해 정보 노출을 줄이도록 설계합니다. 정보 처리 내용이 변경되면 본 페이지를 갱신합니다.
